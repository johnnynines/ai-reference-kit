# Standard Report Structure — Internal Documents

This file defines the standard structure for internal reports and memos at
Northpoint Group. Use this as the default format for any document I produce
unless I specify otherwise.

---

## Standard Internal Memo (1–2 pages)

```
TO: [Recipient Name, Title]
FROM: Alex Rivera, Director of Operations
DATE: [Date]
RE: [Subject — be specific, not vague]

SUMMARY
[2–4 sentences maximum. What is this memo about, and what does the reader
need to know or decide? This section must stand alone — a reader who only
reads this block should walk away knowing the key point.]

BACKGROUND
[Brief context — only what the reader needs to understand the issue. Do not
repeat information they already know. 1–3 short paragraphs maximum.]

FINDINGS / ANALYSIS
[The substance of the memo. Use headers and numbered lists where the content
is complex. Tables for comparative data. Keep each paragraph to one idea.]

RECOMMENDATION
[State your recommendation clearly. If there are options, present them as
Option A / Option B with tradeoffs, then state which you recommend and why.]

NEXT STEPS
[Numbered list. Owner and due date for each item. No vague action items —
every item must have a named person responsible.]

ATTACHMENTS (if applicable)
[List with descriptive titles, not just filenames.]
```

## Ops Dashboard Report (Monthly — Board / Leadership)

Structure for the monthly Operations Dashboard delivered to the Managing Partner:

```
1. HEADLINE METRICS (table)
   - Current month vs. prior month vs. target
   - Traffic light indicator (Green / Yellow / Red)

2. UTILIZATION SUMMARY
   - Overall firm UR this month
   - By office
   - By service line
   - Bench headcount and days

3. FINANCIAL OPERATIONS
   - Overhead as % of revenue (vs. target)
   - Key variances (over/under budget by category)
   - Any payments or commitments over $25K

4. PEOPLE AND RESOURCING
   - Open roles and hiring pipeline status
   - Notable departures or new starts
   - PTO and leave impacts on capacity

5. OPERATIONAL FLAGS
   - Issues requiring leadership attention
   - Risks on the horizon
   - Decisions needed from leadership (be explicit,  do not bury decision requests)

6. WINS
   - Process improvements, cost saves, efficiency gains this month
   - Keep this section short — 3–5 bullets maximum
```

## Formatting Rules

- **Font and layout:** Managed by document template. Do not manually override.
- **Tables:** Use for any comparison involving 3+ variables.
- **Bullet points:** Acceptable for lists of 4+ items. Not a substitute for
  analysis — do not use bullets to avoid writing complete thoughts.
- **Length guidance:**
  - Memo: 1–2 pages maximum
  - Dashboard: 1 page (with appendices if needed)
  - Proposal/analysis: No hard limit, but keep the executive summary to 1 page
- **Always include:** Date, author, and version number (v1.0, v1.1, etc.)
- **Never include:** Watermarks, decorative borders, clipart, or non-standard fonts
