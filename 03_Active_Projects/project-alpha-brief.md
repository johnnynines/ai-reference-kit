# Project Brief — Operations Tech Stack Consolidation

## Project Code Name
Alpha (internal only — do not use externally)

## Official Project Name
Operations Technology Stack Consolidation

## Status
In Progress — Phase 2 of 3

## Owner
Alex Rivera (Director of Operations)

## Objective
Reduce the number of disconnected operational software tools from 14 to 7 by
consolidating overlapping systems, eliminating redundant licenses, and migrating to
a unified platform where possible. Target completion: Q4 2026.

## Why This Matters
Our current tool sprawl costs approximately $340K per year in redundant licenses and
generates significant data-consistency issues between systems. Phase 1 analysis
identified 6 tools with direct functional overlap and 3 with no current active users.
Consolidation is projected to save $180K–$220K annually and reduce IT support burden
by an estimated 30%.

## Phase Summary

### Phase 1 — Completed (Q1 2026)
Audit of all 14 operational tools: usage rates, contract terms, renewal dates,
and functional overlap mapping. Output: Tool Rationalization Report (stored in
SharePoint: Ops > Projects > Tech Stack Consolidation).

### Phase 2 — In Progress (Q2–Q3 2026)
Vendor evaluation for unified platform. Current shortlist: NetSuite expansion,
Microsoft Viva suite, and a point solution from Ramp. Priya Nair is leading the
financial modeling. Decision expected by August 2026.

### Phase 3 — Planned (Q4 2026)
Migration and decommission of redundant tools. Change management plan to be
developed in Phase 2.
