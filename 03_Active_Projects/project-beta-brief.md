# Project Brief — Q3 Capacity Planning Cycle

## Project Code Name
Beta (internal only)

## Official Project Name
Q3 2026 Capacity Planning and Staffing Review

## Status
Active, recurring, quarterly process

## Owner
Alex Rivera (Director of Operations) in partnership with Tom Weiss (Head of Resourcing)

## Objective
Produce the Q3 staffing plan by July 31, 2026. This plan allocates all billable
consultants across current and incoming engagements, identifies bench risk, and
flags any hiring gaps that cannot be covered by internal movement.

## Key Outputs Required
1. **Utilization Forecast** — Projected UR for each consultant through September 30
2. **Bench Risk Report** — Consultants projected to go unbilled for 3+ weeks
3. **Hiring Gap Analysis** — Skills or capacity shortfalls that require new hires
   or contractor deployment
4. **Engagement Start/End Calendar** — Visual timeline of all engagements with
   key milestones flagged
